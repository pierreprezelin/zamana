# Contributing to Zamana

Thanks for helping! Bug reports, fixes and feature ideas are all welcome.

## Before you start

- For a bug, open an issue describing how to reproduce it.
- For a feature, open an issue first so we can agree on the idea before you spend time on it.

## Pull requests

1. Fork the repository and create a branch from `dev` (`feat/…` or `fix/…`).
2. Keep one topic per pull request.
3. Add tests for any logic you change.
4. Run `bun run verify` and make sure it passes.
5. Open the pull request against `dev`.
